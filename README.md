# NeuroMap: Ο Εγκέφαλος και η Γλώσσα

Διαδραστικός χάρτης του ανθρώπινου εγκεφάλου για παιδιά και εφήβους. Δείχνει ποιο μέρος του εγκεφάλου μάς βοηθά να καταλαβαίνουμε και να μιλάμε.

**Live:** https://neuromap-delta.vercel.app/

## Τι κάνει

- Δείχνει το αριστερό ημισφαίριο σε πλάγια όψη, όπως το σχεδιάζουν οι νευρογλωσσολόγοι.
- Πατάς μια περιοχή και βλέπεις τι κάνει και με ποιο μέρος του λόγου σχετίζεται.
- Τα χρώματα χωρίζουν τις περιοχές σε τρεις ομάδες:
  - ρήματα και γραμματική
  - ουσιαστικά και σημασία
  - σύνδεση και ενσωμάτωση

## Περιοχές

| Περιοχή | Σχετίζεται με |
|---|---|
| Broca | Σύνταξη και γραμματική, ρήματα |
| Προκινητικός φλοιός | Ρήματα δράσης |
| Wernicke | Κατανόηση λόγου, ουσιαστικά |
| Οπίσθιος κρόταφος | Ρήματα και γεγονότα |
| Πρόσθιος κρόταφος | Ουσιαστικά και σημασία |
| Γωνιώδης έλικα | Σχέσεις, προθέσεις |
| Υπερχείλιος έλικα | Ήχοι και φωνολογική μνήμη |
| Τοξοειδής δεσμίδα | Σύνδεση Wernicke και Broca |

## Σημείωση

Ο χάρτης είναι σχηματικός και εκπαιδευτικός. Η διάκριση ανά μέρος του λόγου είναι τάση και όχι αυστηρός κανόνας: οι περιοχές επικαλύπτονται και δουλεύουν ως δίκτυο. Δεν αντικαθιστά ιατρική ή νευρολογική πληροφόρηση.

## Τρέξιμο τοπικά

Άνοιξε το `index.html` στον browser, ή τρέξε `npx serve` στον φάκελο.
